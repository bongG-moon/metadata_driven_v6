[v6 메인 필터 자연어 정규화본]
이 문서는 기존 main_variable.txt의 필터 해석 사실을 v6의 명시적 카드 문법으로 다시 표현한 검토용 자연어 입력이다.
각 카드는 기존 도메인 패키지에 등록된 field 대상에 사용자 표현을 추가하며, 실행 코드나 쿼리 또는 비밀값을 포함하지 않는다.

별칭 카드의 안정 식별자는 field:DATE이고 대상 유형은 field, 대상 키는 DATE입니다.
사용자가 '날짜', '일자', '기준일', '작업일', '오늘', '금일', '어제', '전일', 'date', 'work date'라고 말하면 DATE 필드로 해석하세요.

별칭 카드의 안정 식별자는 field:OPER_NAME이고 대상 유형은 field, 대상 키는 OPER_NAME입니다.
사용자가 '공정', '작업공정', 'operation', 'process', 'oper name'라고 말하면 OPER_NAME 필드로 해석하세요.

별칭 카드의 안정 식별자는 field:OPER_NUM이고 대상 유형은 field, 대상 키는 OPER_NUM입니다.
사용자가 '공정번호', '공정 차수', 'oper num', 'oper no'라고 말하면 OPER_NUM 필드로 해석하세요.

별칭 카드의 안정 식별자는 field:TECH이고 대상 유형은 field, 대상 키는 TECH입니다.
사용자가 '제품 기술'라고 말하면 TECH 필드로 해석하세요.

[추가 유지 규칙]
ORG 값이 x16 또는 X8처럼 x 또는 X와 숫자를 붙인 표현이면 접두사를 제외한 16 또는 8로 해석한다.
DEVICE_DESC 조건은 사용자가 해당 필드나 제품 설명을 명시한 경우에만 사용한다.
EQP_MODEL 조건에 여러 문자 값이 들어오면 여러 값 포함 조건으로 적용한다.
ORG의 실제 컬럼 후보 ORG, ORGANIZ_CD, organiz_cd와 EQP_MODEL의 실제 컬럼 후보 EQP_MODEL, EQP_MODEL_CD는 기존 데이터셋 메타데이터에서 유지한다.
