# 제조 조회 기준에 대한 현장 용어 메모

날짜, 일자, 기준일, 작업일, 오늘, 금일, 어제, 전일, date, work date라고 말하면 조회 날짜를 뜻해. 오늘이나 어제처럼 상대적인 표현은 질문한 시점을 기준으로 계산해 줬으면 해.

공정, 작업 공정, operation, process, oper name은 공정 이름을 뜻해. 공정 번호, 공정 차수, oper num, oper no는 공정의 번호나 차수를 뜻하고 공정 이름과는 구분해야 해.

제품을 좁혀 볼 때는 제품 기술, 제품 용량, 제품 모드, 첫 번째와 두 번째 패키지 종류, 조직 코드, lead count, 제품 코드, device와 제품 설명을 주로 사용해. 현장에서는 제품 모드를 MODE나 Mode라고도 하고 제품 용량을 DEN이나 DENSITY라고도 말해. 패키지 종류는 PKG1, PKG2라고 줄여 부르기도 해.

조직 코드는 ORG 또는 organization code라고도 해. x16이나 X8처럼 앞에 x를 붙여 말하면 실제 조직 값 16이나 8을 뜻해.

제품 코드는 MCP NO, MCP_NO, MCP sales no처럼 여러 방식으로 부른다. 제품 설명은 사용자가 명시적으로 “제품 설명”이나 DEVICE DESC라고 말했을 때만 조건으로 사용하고, device code와 혼동하지 않아야 해.

HBM, 3DS, TSV와 2Hi, 4Hi, 8Hi는 TSV 적층 종류를 기준으로 제품을 찾는 표현이야.

장비를 찾을 때는 장비 ID와 장비 모델을 구분해. EQPID라고 하면 장비 ID이고, equipment model·장비 기종·설비 모델은 장비 모델을 뜻해.

Lot ID는 특정 Lot을 찾는 기준이고 Recipe ID 또는 레시피는 작업 Recipe를 찾는 기준이야. “장비”처럼 ID인지 모델인지 알 수 없는 표현만 들어오면 임의로 정하지 말고 어떤 기준을 원하는지 쉬운 말로 확인해 줘.
