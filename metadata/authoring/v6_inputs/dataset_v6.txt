# 제조 분석에 사용하는 업무 자료 메모

우리 팀이 분석에 쓰는 자료는 당일 생산 실적, 생산 이력, 현재 재공, 재공 이력, 생산 계획, 장비 배정 현황, 장비와 제품별 UPH, 현재 LOT 현황, HOLD 이력, 제품 기준정보야. 아래 내용은 자료의 업무 의미를 설명한 것이고 내부 등록 번호나 물리 컬럼 매핑을 적은 것은 아니야.

## 당일 생산 실적

오늘 또는 당일 생산 실적을 볼 때 쓰는 Oracle 자료야. 작업일을 반드시 정해서 조회하고 생산 수량을 합산하면 생산량이 돼. 작업일, 근무조, 공장과 FAB, 제품 family·기술·용량·모드·패키지 종류·lead·제품 코드·device, 공정 이름과 공정 순서 같은 항목으로 나눠 볼 수 있어. 생산 수량과 wafer 환산에 필요한 net die 수량도 함께 확인할 수 있어.

상세 결과의 기본 표시 항목은 제품 기술, 용량, 모드, 두 패키지 종류, lead, 제품 코드, device, 공정 이름과 생산 수량이야.

## 생산 이력

과거 날짜의 생산 실적을 볼 때 쓰는 Oracle 자료야. 날짜를 반드시 정해야 하고 업무 항목과 생산량 계산 방식은 당일 생산 실적과 같아. “당일”, “오늘”이라는 말이 없고 과거 날짜를 물으면 이 자료를 사용해.

상세 결과의 기본 표시 항목도 당일 생산 실적과 같은 제품 속성, device, 공정 이름과 생산 수량이야.

## 현재 재공

지금 재공, 현재 재공, 금일 현재 재공을 볼 때 사용하는 Oracle 자료야. 작업일, 근무조, 제품 속성, 공정 이름과 순서로 나눠 볼 수 있고 재공 수량을 합산해 보여줘. BOH나 아침 재공처럼 하루 시작 시점을 묻는 질문에는 이 자료를 사용하지 않아.

상세 결과의 기본 표시 항목은 제품 기술, 용량, 모드, 두 패키지 종류, lead, 제품 코드, device, 공정 이름과 재공 수량이야.

## 재공 이력

과거 재공과 하루 시작·마감 재공을 확인하는 Oracle 자료야. 날짜가 필요하고 재공 수량을 합산해 보여줘. 이 자료의 날짜는 해당 날짜가 끝날 때의 재공을 뜻하므로, 어느 날의 아침 재공은 하루 전 날짜의 재공 이력을 조회해야 해.

상세 결과의 기본 표시 항목은 현재 재공과 같은 제품 속성, device, 공정 이름과 재공 수량이야.

## 생산 계획

Goodocs에서 관리하는 일별 투입 계획과 생산 목표 자료야. 날짜와 제품 기술·용량·모드·패키지 종류·lead·조직·제품 코드별로 투입 계획 수량과 생산 목표 수량을 볼 수 있어. 이 자료에서는 제품 코드를 MCP NO라고 부르고 별도의 device 항목은 없어. 현장에서는 투입 계획을 INPUT 계획이라고도 하고 생산 목표를 OUT 계획, TARGET이라고도 불러. 이 문서의 날짜 표기는 보통 2026-06-20처럼 하이픈이 들어간다.

상세 결과의 기본 표시 항목은 제품 기술, 용량, 모드, 두 패키지 종류, lead, 제품 코드, 날짜, 투입 계획 수량과 생산 목표 수량이야.

## 장비 배정 현황

공정과 제품 조건에 어떤 장비가 배정되어 있는지 확인하는 Oracle 자료야. 장비 ID, 장비 모델, press 수, 공정, 제품 속성, Lot과 Recipe를 볼 수 있어. 장비 대수는 별도 수량 항목이 아니라 조건에 맞는 장비 ID를 중복 없이 센 값이야. 상세 조회에서는 장비 ID를 기본으로 보여줘.

## 장비·제품별 UPH

장비 모델, Recipe, 공정과 제품 조건별 평균 UPH를 확인하는 Oracle 자료야. 기본 상세 결과에는 장비 모델, Recipe, 공정을 보여줘. UPH는 이미 평균 성격의 값이라 서로 더하면 안 돼. 사용자가 별도 묶음을 말하지 않으면 장비 모델·Recipe·공정별 값을 유지하고, 공정 차수별이나 장비 기종별처럼 묶음을 명시했을 때만 그 묶음의 평균을 계산해. press 수와 제품 코드는 질문에서 요구할 때만 추가로 보여줘.

## 현재 LOT 현황

현재 재공에 있는 Lot의 작업 상태를 보는 Oracle 자료야. Lot ID, 공정, 장비, 제품 속성, die 수량, wafer 수량, 공정 유입 후 TAT, 누적 TAT, HOLD 상태와 사유를 확인할 수 있어. Lot 건수는 Lot ID를 중복 없이 세고, die 또는 unit 수량은 생산 단위 수량을 합산하며, wafer 수량은 wafer 수량 항목을 합산해. HOLD 상태가 OnHold이면 보류 중인 Lot이야. 상세 결과에는 Lot ID, 공정, die·wafer 수량, 두 TAT, HOLD 상태·사유와 Lot 상태를 기본으로 보여줘.

## HOLD 이력

HOLD된 Lot의 발생 사유와 시각, 상세 설명을 보는 Oracle 이력이야. 어떤 Lot을 볼지 정해야 조회할 수 있어. HOLD Lot 건수는 Lot ID를 중복 없이 세고, HOLD die·unit 수량은 생산 단위 수량을 합산해. 상세 결과에는 Lot ID, 공정, HOLD 발생 시각, HOLD 코드와 상세 설명을 기본으로 보여줘. 같은 대화에서 직전에 찾은 Lot들의 HOLD 이력을 이어서 물으면 직전 결과의 Lot 목록을 사용하고, 한 번에 최대 200개까지만 조회해.

## 제품 기준정보

현재 시점의 제품 기준 속성을 device 기준으로 확인하는 자료야. 제품 기술, 용량, 모드, 두 패키지 종류, lead와 제품 코드를 함께 볼 수 있고 제품별 수율 기준값도 있어. 수율은 숫자로 비교하거나 높은 순서와 낮은 순서로 볼 수 있어. 상세 결과에는 device, 수율, 제품 모드와 lead를 기본으로 보여줘.

자료를 실제 Oracle·Goodocs 연결 정보와 결합하는 일은 운영자가 승인한 소스 레지스트리가 담당해. 이 업무 메모에서 연결 문자열, 쿼리, 내부 참조 이름이나 컬럼 타입을 추측해서 만들 필요는 없어.
